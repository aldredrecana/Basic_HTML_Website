# Basic_HTML_Websit

Frontend Developer Portfolio - HTML Structure

A simple multi-page website built using HTML only. This project focuses on structuring a website semantically — no CSS styling is included, as the goal is to learn how to properly organize a website using semantic HTML elements (header, nav, main, section, article, footer, etc.).

Project Goals
Learn how to create multiple pages on a website
Structure a website semantically using HTML
Structure content in a way that makes it easy to style later
Add SEO meta tags to each page
